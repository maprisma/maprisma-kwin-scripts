# Maprisma KWin scripts

KWin scripts for KDE Plasma, installed with `./install.sh`:

- **omarchy-navigation**: Omarchy window actions KWin lacks (dynamic desktops, move and follow, scratchpad).
- **maprisma-focus-border**: a frame in the colour scheme focus colour around the active window, on desktops Krohnkite tiles. Maprisma Theme mirrors the tiling state into `[Script-maprisma-focus-border]` in kwinrc.
